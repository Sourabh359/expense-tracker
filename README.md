## 🚀 Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Expense summary
  - Total Expenses
  - Total Amount
  - Highest Expense
  - Average Expense
- Search expenses
- Sort expenses
  - Newest First
  - Oldest First
  - Amount Low → High
  - Amount High → Low
  - Title A → Z
  - Title Z → A
- LocalStorage persistence
- Dark Mode
- Form validation
- Error Boundary
- Empty State UI
- Responsive design
- Auto-focus on title input after adding an expense
- React.memo optimization
